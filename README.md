# AURELIA — AI Interior & Renovation Studio

A one-page website for an AI interior design and renovation studio. The hero is a full-screen video that plays forward and backward as you scroll: an old living room turns into a private home cinema.

**Live site:** https://shahzadishq.github.io/AURELIA-/

## Sections
- Scroll-driven video hero with chapter text and a step indicator
- Stats counter and a scrolling materials strip
- Services
- Before / after slider
- Four-step process
- Gallery
- AI concept planner (room, mood and budget)
- Consultation form (demo only, not connected to email yet)

## Files
- `index.html` — the whole page (HTML, CSS and JavaScript)
- `scroll.mp4` — background video, encoded with frequent keyframes so scrubbing stays smooth
- `img/` — still frames taken from the video

## Run locally
Open `index.html` through a local server, for example `python3 -m http.server`, then visit http://localhost:8000.
